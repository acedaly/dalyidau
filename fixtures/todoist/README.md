# Todoist export fixtures

Invented data in the format of Todoist's CSV export (one file per project; a Todoist backup is a
zip of these). Used by `test/tasks-milestone2.test.ts` and `e2e/tasks-m2.spec.ts`. No real tasks.
The column list follows Todoist's help article "Format a CSV file to import into Todoist"; these
files were not produced by Todoist itself, so they don't prove every quirk of a real export.
